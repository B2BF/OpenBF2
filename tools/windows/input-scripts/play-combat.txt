# [TEMP] join-and-spawn: from the loaded-map screen to a spawned soldier (docs/macos-c-input-script.md).
# Coordinates are 800x600: the harness runs +szx 800 +szy 600, which is also the HUD's own layout
# space (Menu_client.zip HUD/HudSetup/SpawnInterface/*.con).
timeout 300
log waiting for the level load
wait-log postLoad #1
wait-ms 15000
capture loaded
# "MAP LOADED, SELECT THE JOIN GAME BUTTON OR PRESS ESCAPE TO ENTER THE GAME" (Swiff menu, window path)
# Click JOIN GAME rather than pressing Escape: Escape went to the main menu in 2 of 5 runs (ai-bot, 2026-11-01).
click 745 583
# The spawn screen opens with its map shown (Bf2MenuMapNode +0x68D is zeroed now; the old
# "press Enter twice" workaround covered for that uninitialised field, R-game-2).
wait-ms 4000
capture spawn-screen-first
capture spawn-screen
# Kit 0, Special Forces (SelectKit0 10 73 246 69: "spawnManager.setPlayerKit 0"); in-game HUD pointer path.
hud-click 130 107
wait-ms 1000
# Spawn point: in spawn mode a press on the map picks the nearest spawn group
# (Bf2MenuMapNode::pickSpawnGroup; within the icon pick radius). The US spawn at Construction Site.
hud-click 432 282
wait-ms 1000
capture selected
# DoneButton 666 539 124 17, mouse area 0 -5 124 22: "hudManager.setDone 1"
hud-click 728 546
wait-ms 10000
capture spawned-1
# Look around a little (mouse look) and capture again.
move-rel 300 0
wait-ms 2000
capture spawned-2
log join-and-spawn done

# [TEMP] demo-controls: the battlerecorder playback controls (loopback --play-demo; docs/tracks/game/demo.md).
# Bindings are the shipped Controls.con ones: right mouse = PIAltFire (free <-> follow camera),
# Space = PIAction (next player, Shift = previous), 1..9 = PIWeaponSelect1..9 (simulation rates
# 0,100,5,25,50,75,150,300,1000), Q = GIRadioComm (Playback Control rose, HUD mode 31),
# T = GITacticalComm (Camera Control rose, HUD mode 30).
# The presses wait 15 s after JOIN GAME: the recorded bots spawn a few seconds into the demo, and
# with nobody alive the follow camera falls back to free flight, as in retail.
# A capture is taken at the next presented frame, so each rose stays held 300 ms after its capture
# (a key-up on the next line can land first; the T rose's side items have no out-time).
# The rose items are clicked with the left button (GIOk) while the rose key is held; the pointer
# starts at the rose centre (move-rel 300 0 = NEXT PLAYER, 0 400 = QUIT).
# Judge from the captures: follow view with the name at the bottom, the PLAY label while paused,
# both roses, a new followed name after NEXT PLAYER, PLAY after the PAUSE click, and the LOGIN
# screen after QUIT. Every capture that is followed by an input waits 300 ms first: a capture is
# taken at the next presented frame, and ctl-next used to show the state after Shift+Space.
